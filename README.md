# Workia

Next.js app with the [shadcn/ui sidebar-07](https://ui.shadcn.com/blocks/sidebar) block — a collapsible sidebar with nested navigation, team switcher, projects, and user menu.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The home route redirects to `/dashboard`, where the sidebar layout is rendered.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- shadcn/ui (sidebar-07 block)
